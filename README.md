# Supplementary Materials

This repository contains the supplementary materials supporting the data related to Extended Reality (XR) in Enhancing Secondary Education:

**Title**

The Role of Extended Reality (XR) in Enhancing Secondary Education: A Comprehensive Review

## Files

- **Paper_Dataset.xlsx** – Bibliographic dataset of all studies included in the systematic review.
- **Paper_Challenges_Mapping.xlsx** – Dataset containing the thematic mapping of challenges identified (Limited infrastructure, Teacher Readiness, etc) across the included studies. 
- **Paper_Domain_Classification.xlsx** – Dataset containing the domain classification (Interactive Skill Acquisition, Collaborative Problem-Solving, etc) of the included studies.
- **Paper_Role_Classification.xlsx** – Dataset containing the classification of the roles identified (Facilitating Personalized and Inclusive Learning Experiences, Supporting Cognitive and Practical Skill Development, etc) from the included studies.
- **Clinical_Abstract_Role_Results_Report.xlsx** – Bibliographic information and publication metadata for the studies included in the review.
- **PRISMA.pdf** – PRISMA 2020 flow diagram illustrating the study identification, screening, eligibility assessment, and inclusion process.

These materials are provided to support the transparency, reproducibility, and verification of the systematic review methodology and findings.
