# Supplementary Materials

This repository contains the supplementary materials supporting the systematic review:

**Title**

The role of extended reality in enhancing secondary education: A systematic review

## Files

- **Paper_Dataset.xlsx** – Bibliographic dataset of all studies included in the systematic review.
- **Challenges_Mapping_Dataset.xlsx** – Dataset containing the thematic mapping of challenges identified across the included studies.
- **Domain_Classification_Dataset.xlsx** – Dataset containing the domain classification of the included studies.
- **Role_Classification_Dataset.xlsx** – Dataset containing the classification of the roles identified from the included studies.
- **Clinical_Abstract_Role_Results_Report.xlsx** – Bibliographic information and publication metadata for the studies included in the review.
- **PRISMA_Flow_Diagram.png** – PRISMA 2020 flow diagram illustrating the study identification, screening, eligibility assessment, and inclusion process.

These materials are provided to support the transparency, reproducibility, and verification of the systematic review methodology and findings.
